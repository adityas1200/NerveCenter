# Document and report quality

- Start with the audience, decision, and expected reading time.
- Use a clear outline before drafting.
- Lead with an executive summary for long reports.
- Keep paragraphs short and use tables when they improve comparison or evidence traceability.
- Separate facts, analysis, decisions, recommendations, and open questions.
- Cite external claims and link internal evidence by stable ID or artifact.
- Preserve the user's template, styles, section order, and required fields when editing an existing document.
- Use appendices for raw logs, query output, detailed timelines, and ticket inventories.
- Render the final document and inspect pagination, headings, tables, figures, references, headers, footers, and orphaned content.
- Test whether a reader without conversation context can identify the conclusion and next action.

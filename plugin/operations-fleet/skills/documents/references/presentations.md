# Presentation quality

## Story before slides

Write a one-line purpose and a slide outline before creating the deck. Each slide should answer one question and its title should state the conclusion or topic clearly.

For an operations review, a strong sequence is often:

```text
Executive result
Volume and service performance
Important incidents and causes
Changes and recoveries
Risks, blockers, and decisions
Next period priorities
Appendix and definitions
```

## Design

- Use the approved template and brand assets when available.
- Prefer a chart, timeline, process, or comparison that explains the point over decorative shapes.
- Keep text concise and left aligned for body content.
- Use consistent spacing, hierarchy, and number formats.
- Avoid repeating one card layout on every slide or filling every space.
- Explain charts with a takeaway, timeframe, unit, source, and relevant caveat.
- Use an appendix for ticket-level detail.

## QA

Render every slide. Inspect legibility, overflow, clipping, alignment, contrast, chart labels, image quality, source notes, placeholders, and speaker notes. Reconcile every important number with the source ledger.

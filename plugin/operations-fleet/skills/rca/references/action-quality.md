# High-quality RCA actions

An RCA action is useful when another person can tell whether it is complete and whether it reduces risk.

For each action record:

```text
Action
Risk or causal condition addressed
Owner
Priority
Target date or event
Completion evidence
Verification method
```

Balance four types:

- containment or immediate recovery;
- durable correction of the causal mechanism;
- earlier detection or better evidence;
- prevention or blast-radius reduction.

Avoid actions such as "be more careful," "monitor closely," or "add tests" without naming the exact condition, signal, test, and expected result. Do not propose a complex platform rebuild when a smaller control addresses the demonstrated risk.

Reference: [Google SRE postmortem culture](https://sre.google/sre-book/postmortem-culture/).
